# 𖹭.ᐟ.ᐟTUMBLR THEME: Modificação pessoal a partir do theme da usuária @natsyme

Nome do theme: "Dream of Destruction", com inspiração no anime Neon Genesis Evangelion. O theme original possuía um design que me agradava, assim como funcionalidades interessantes (opção de personalizar o favicon, imagens das tags e o cursor) no entanto, eu sentia que faltava algumas coisas que o deixaria ainda mais estético, como por exemplo: hovering nos links e a opção de múltiplos backgrounds. Adicionei um ''right click disable" junto a um popup, com um texto simbólico apenas para fins estéticos.
A imagem à direita foi modificada pelo usuário <a href="https://www.deviantart.com/johnsonting/art/Nike-428921273">johnsonting</a>. Já a imagem à esquerda foi criada por mim.
